Frequently asked questions

A code says “Not GS1”, but its text looks like GTIN and lot. Why?

GS1 DataMatrix, GS1-128 and GS1 QR codes start with a special FNC1 character. A plain DataMatrix or Code 128 with the same text has no FNC1, so GS1 scanners at a checkout or warehouse won’t read a GTIN, lot or expiry from it. Make the code again in Create with the GS1 symbology.

What does “Check separators” mean?

Variable-length fields such as lot or serial must end with a separator (FNC1 in the code, GS when scanned). The scanned data was missing one, and the app restored it from the field lengths. Where two splits are possible, check the code that printed it.

Where do I get a GTIN?

From your local GS1 member organization — in the US, GS1 US. DataMatrix Junior makes barcodes from numbers you already own; it doesn’t issue GTINs. See Learn › Where to get a GTIN in the app.

Which size should I print?

Choose where the code will be scanned (retail checkout, healthcare, distribution) in Export: the app offers the module sizes (X-dimension) from the GS1 tables and marks the target with a star. Never stretch a barcode image to fit; export it at the right size instead.

Where are my scans?

The last few are under the result on the Scan screen; all of them are in Library › Scans. The app keeps the latest 200 on your iPhone. Swipe a scan to delete it, tap Select to delete several, or use Clear history.

How do I scan a batch of codes?

On the Scan screen, tap Start batch and scan the codes one after another. Each new code plays a short sound and adds to the counter; a code that is already in the batch is skipped. Tap Export CSV to save or send the batch, and End batch when you are done. A batch has no size limit and stays on your iPhone until you end it.

How do I open my scans in Excel?

Export CSV in a batch, or Export as CSV in Library › Scans (all scans, search results, or the scans you pick with Select), then send the file to Files, Mail or another app. Each scan is one row: time, barcode type, status, GTIN, lot, expiry, serial, the element string and the data as read. Columns are separated by a semicolon where the decimal separator is a comma, as Excel expects there.

Can the app check Chestny ZNAK marking codes?

It checks their structure: format, product group, part lengths and separators. Whether a code was issued and is valid is confirmed only by the operator of the national system.
